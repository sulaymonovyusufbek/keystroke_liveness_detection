# Features

Auto-generated by `kl.report.write_features_md`. One code path (`kl.features`) is used for human and bot sessions. Keys are identified by KEYCODE (Backspace 8, Delete 46, Shift 16); LETTER is never used.

Model input transform (`kl.model.FeatureTransform`): bounded rates in [0, 1] (`correction_rate`, `lev_norm`, `pause_rate`, `rollover_rate`) are used as they are; every other feature is passed through the signed log `y = sign(x) * log1p(|x|)`; then a RobustScaler (median / IQR) fitted on the TRAIN split only.

Revision 1 (2026-09-24): `flight_cv` was removed (undefined when the mean flight is ~0 because of rollover; it reached ~7e7 on the train split); `flight_median` and `flight_iqr` were added.

Worked example (3 keys, SENTENCE=`abc`, USER_INPUT=`abd`):

| key | PRESS | RELEASE | KEYCODE |
|---|---|---|---|
| a | 0 | 100 | 65 |
| b | 200 | 280 | 66 |
| c | 450 | 560 | 67 |

hold = [100, 80, 110], pp = [200, 250], rr = [180, 280], flight = [100, 170] (ms). Standard deviations are population standard deviations (ddof = 0).
